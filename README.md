# wife-bots

Два Telegram-бота (тренер + нутрициолог), один процесс, одна Google-таблица (`WIFE_SHEET_ID`), webhook (aiohttp) или polling.

## Запуск

1. Скопируй `.env.example` → `.env`, заполни `WIFE_*`.
2. Доступ service account к таблице (редактор).
3. `pip install -r requirements.txt`
4. **Polling (dev):** `WIFE_USE_POLLING=1` или без `WIFE_RENDER_EXTERNAL_URL` → `python -m app.main`
5. **Webhook:** задай `WIFE_RENDER_EXTERNAL_URL` (https, без слэша в конце) и `PORT`; опц. `WIFE_WEBHOOK_SECRET` → `python -m app.main`

Пути webhook: `/webhook/trainer`, `/webhook/nutrition` (относительно `WIFE_RENDER_EXTERNAL_URL`).

## Ручной чек-лист сценариев

### Общее
- [ ] `WIFE_ALLOWED_CHAT_IDS` — только нужные чаты; чужой чат отвергается.
- [ ] Таблица создаётся: листы и шапки после старта; пустой «Упражнения» сидится из `data/exercises_seed.json`.

### Тренер
- [ ] `/start` / `/menu` — меню с inline-кнопками.
- [ ] Отправка длинного текста или `/plan …` — план в JSON, сохранение в «Состояние» и «План_тренировок».
- [ ] «Последний план» — показ JSON.
- [ ] «Старт тренировки» → «Поехали!» — разминка и сессия, время фиксируется при старте.
- [ ] Живая сессия: подход (текст/голос), оценка тяжести 1–10, таймер отдыха 60/90/120 с напоминанием.
- [ ] «Занят тренажёр» — выбор другого упражнения из плана.
- [ ] «Аналоги ×3» — три id из базы через Gemini.
- [ ] «Техника» — overlay с советами, «Закрыть» удаляет.
- [ ] «Пропуск сета», «Прервать тренировку».
- [ ] Завершение: сохранение сессии, бонус ккал, отчёт (без опроса после тренировки).
- [ ] Финиш: запись «Сессии» + «Прогресс_упражнений», оценка ккал, бонус в «Состояние», уведомление нутрициологу.
- [ ] Отчёты д/н/м; PNG календарь текущего месяца.
- [ ] Напоминания тренировки (с 4-го дня после сессии, 09:00 и 19:00) — idempotent ключи `remind_train_*`.

### Нутрициолог
- [ ] Онбординг: рост → возраст → пол → активность → цель → вес (явно).
- [ ] Еда: текст / голос / фото (без caption) → staple+OFF+Gemini → «Питание» + кэш.
- [ ] Низкая confidence — запрос «проверь».
- [ ] Вес: число в чат; фото весов — распознавание.
- [ ] «Копилка дня» — прогресс-бары к нормам.
- [ ] «Покупки ~4 дня» — ответ Gemini.
- [ ] Утренний пинг веса ~8:00 (идемпотентно).
- [ ] `WIFE_MEAL_REMINDER_TIMES` — напоминания о еде.
- [ ] Пересчёт норм при весе и ежедневно (scheduler); строка в «Нормы_КБЖУ»; бонус от тренера.

## Примечания

- Google Calendar **не** используется (нет env и кода).
- Секреты только с префиксом `WIFE_`.
